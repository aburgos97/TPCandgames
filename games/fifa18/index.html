Cómo se calculan los puntos
VICTORIA: 3 pts  ·  EMPATE: 1 pt cada uno  ·  DERROTA: 0 pts

Bonus upset: Si el ganador tiene menos ★ que el rival, +0.5 pts por cada 1.5★ de diferencia.
Ej: ★★ gana a ★★★★★ (3★ diff) = 4.0 pts  ·  ★★★ gana a ★★★★★ (2★ diff) = 3.5 pts

Bonus goleada: +0.5 pts si la diferencia es 3 goles o más.
